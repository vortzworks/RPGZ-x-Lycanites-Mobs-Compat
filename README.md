# RpgZ x Lycanites Compat (Forge 1.20.1)

Small add-on so Lycanites Mobs loot goes into RpgZ corpses instead of falling on the ground.

Needs: Forge 1.20.1 (47.x), RpgZ Fixed 0.6.0 (Forge), Lycanites Mobs 1.20.1 alpha. Put this jar in `mods/` alongside them.

## Build
- GitHub: push this folder to a repo, open the Actions tab, run "build", download the jar from the run's artifacts.
- Local: JDK 17, Gradle 8.1.1+, run `gradle build`; jar is in `build/libs`.
